## ⭐Finite State Machine(FSM，有限狀態機) — 為什麼電路需要「現在處於哪個狀態」？

主線位置：Teacher Transcript／`逐字稿_03_0922.txt`／Session=03／L8–L15
對齊參考：`講義_ch01_Verilog structural and dataflow modeling`／PDF viewer page 31

上一堂老師只預告 FSM，這一堂才正式開始講。不過老師也明確說**現在不會深入**，所以這裡先掌握用途與 State(狀態)的概念，不超前講完整 FSM coding architecture。

### 1. FSM 在解決什麼問題？

前面學的 Adder、MUX 等比較像：

> 輸入現在是多少 → 輸出就算出多少。

但實際晶片常常需要知道：

> **我現在進行到哪一個階段？**

例如某些子電路：

* 現在要運作；
* 等一下要暫停；
* 某個階段才開啟；
* 其他階段不要動。

老師用這個角度介紹 FSM：把系統分成幾個 State(狀態)，再依目前狀態控制哪些部分要運作。

所以最簡單的 mental model 是：

$$
\boxed{\text{FSM = 用「狀態」管理電路現在應該做什麼}}
$$

---

### 2. State(狀態)是什麼？

老師舉了一個三個狀態的例子：

```text
S0 → S1 → S2
```

並用 clock cycle 說明：

```text
第 1 個 cycle：S0
第 2 個 cycle：S1
第 3 個 cycle：S2
```

也就是電路不是永遠做同一件事，而是可以隨時間進入不同狀態。

這裡跟剛學過的 Flip-Flop/Register 有關：

> FSM 必須「記得自己目前在哪個 state」。

所以 FSM 本質上屬於 Sequential Logic(循序邏輯)的應用。

---

### 3. Traffic Light(紅綠燈)直覺

老師用紅綠燈當直覺例子。

可以想像：

```text
S0 = 綠燈
S1 = 黃燈
S2 = 紅燈
```

再搭配 Counter(計數器)，例如某個 state 停留一段時間後才進下一個 state。

所以 FSM 很適合描述：

```text
現在在哪一階段
        ↓
這階段做什麼
        ↓
什麼時候切換到下一階段
```

老師就是用 traffic light 說明這是一種很基本的 Verilog design pattern。

---

### 4. 目前先不要超前學什麼？

這堂此處老師沒有深入展開：

* Moore / Mealy machine
* next-state logic 的完整寫法
* state encoding
* 完整 FSM 三段式 coding style

所以現在**不用先背這些**。

本段只要掌握：

$$
\boxed{\text{State = 系統目前所處的工作階段}}
$$

以及：

$$
\boxed{\text{FSM = 依 State 控制系統行為，並隨時間切換 State}}
$$

講義 page 31 將這個主題標為 `Finite State Machine (FSM)`，並放了 divide-by-3 counter 的例子；但老師這裡只做入門介紹，沒有深入該電路。
