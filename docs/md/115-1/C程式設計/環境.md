# 環境

## Makefile


```makefile
c = g++
t = Q1 Q2 Q3 Q4
ob = Q1.o Q2.o Q3.o Q4.o

all: $(t)

$(ob): %.o: %.cpp
	$(c) -c $< -o $@

$(t): %: %.o
	$(c) -o $@ $<

clean:
	rm -f $(t) $(ob)

```

1. 為何是寫`$(ob): %.o: %.cpp`？
   因為整句其實在說：對 Q1.o Q2.o Q3.o Q4.o 這四個 target，凡是符合 %.o 的，就去找同名的 %.cpp 當 prerequisite。==所以 $(ob): 對應 %.o==
2. 為何是寫`$(t): %: %.o`？
   對 TARGETS 裡的每一個 target，都去找「同名的 .o 檔」當作它的 prerequisite。==所以 $(t): 對應  %==



## 指令

- 記事本：`nano <檔名>`
- 記事本快捷鍵：
    復原： `Alt + U`
    重做： `Alt + E`
- 編譯與執行： `make clean && make && ./<檔名>`
- 複製貼上：滑鼠選取按右鍵

## 快捷鍵

切換終端分頁： Alt + 1 、 Alt + 2


## 流程


```
toush Q1.cpp Q2.cpp Q3.cpp Q4.cpp   # 創建檔案
nano Q1.cpp                         # 編輯
toush makefile                      # 創建檔案
nano makefile                       # 寫上內容
make clean && make && ./<檔名>      # 編譯和執行

```
