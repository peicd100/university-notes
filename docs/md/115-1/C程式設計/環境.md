# 環境

## Makefile


```makefile
c = g++

t = Q1 Q2 Q3 Q4
o = Q1.o Q2.o Q3.o Q4.o

all: $(t)

$(o): %.o: %.cpp
	$(c) -c $< -o $@

$(t): %: %.o
	$(c) -o $@ $<

clean:
	rm -f $(t) $(o)
```

## 指令

- 記事本：`nano <檔名>`
- 記事本快捷鍵：
    復原： `Alt + U`
    重做： `Alt + E`
- 編譯與執行： `make clean && make && ./<檔名>`

## 快捷鍵

切換終端分頁： Alt + 1 、 Alt + 2


## 流程


```
toush Q1.cpp                    # 創建檔案
nano Q1.cpp                     # 編輯
toush makefile                  # 創建檔案
nano makefile                   # 寫上內容
make clean && make && ./<檔名>  # 編譯和執行

```
