3.按下 ok

![alt text](images/燒錄板子-1.png)

4.按下 “Open Synthesized Design”


![alt text](images/燒錄板子-2.png)


5.開啟腳位設定

![alt text](images/燒錄板子-3.png)

![alt text](images/燒錄板子-4.png)


7.設定腳位

![alt text](images/燒錄板子-5.png)


8.按下 ctrl + s，命名檔案(盡量以 top 檔案命名)

![alt text](images/燒錄板子-6.png)


9.(非必要) sources -> constraints -> constrs_1 -> top 檔案名.xdc

![alt text](images/燒錄板子-8.png)

![alt text](images/燒錄板子-9.png)

![alt text](images/燒錄板子-11.png)

![alt text](images/燒錄板子-12.png)
