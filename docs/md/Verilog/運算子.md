# 運算子

## 一句話先懂

Verilog 最容易混淆的是三組東西：  
bitwise vs logical、`==` vs `===`、運算式位寬 vs 指派左值位寬。

## 核心規則

- bitwise 是逐 bit 運算，logical 是把整個 operand 當布林值判斷。
- reduction 會把整個 vector 壓成 1 bit。
- arithmetic、comparison 與 shift 都會受到位寬與 signedness 影響。
- `==` / `!=` 遇到 `x/z` 可能得到 unknown；`===` / `!==` 會把 `x/z` 當成可比較值。
- 指派到左邊之前，先想運算式自己的位寬，再想最後會不會被截斷或延伸。

## 常用模板或例子

### Bitwise operators

```verilog
~a
a & b
a | b
a ^ b
a ~^ b
```

- 逐 bit 計算。
- 輸出寬度通常跟 operand 位寬對齊。

### Logical operators

```verilog
!a
a && b
a || b
```

- 把整個 operand 視為 true / false。
- 結果永遠是 1 bit。

### Reduction operators

```verilog
&in   // reduction AND
~&in  // reduction NAND
|in   // reduction OR
~|in  // reduction NOR
^in   // reduction XOR
^~in  // reduction XNOR
~^in  // reduction XNOR
```

- 全部都是 unary reduction operator，會把整條 vector 壓成 `1 bit`。
- 可以把它想成「把整條 bus 一路折疊運算到最後只剩 1 個 bit」。

| 寫法 | 名稱 | 例子 | 結果說明 |
| --- | --- | --- | --- |
| `&in` | reduction AND | `&4'b1111` | `1'b1`，全部 bit 都是 `1` |
| `&in` | reduction AND | `&4'b1011` | `1'b0`，只要有任一 bit 不是 `1` |
| `~&in` | reduction NAND | `~&4'b1111` | `1'b0`，是 `&` 的反相 |
| `~&in` | reduction NAND | `~&4'b1011` | `1'b1` |
| `|in` | reduction OR | `|4'b0000` | `1'b0`，全部 bit 都是 `0` |
| `|in` | reduction OR | `|4'b1011` | `1'b1`，只要有任一 bit 是 `1` |
| `~|in` | reduction NOR | `~|4'b0000` | `1'b1`，是 `|` 的反相 |
| `~|in` | reduction NOR | `~|4'b1011` | `1'b0` |
| `^in` | reduction XOR | `^4'b1011` | `1'b1`，共有 3 個 `1`，odd parity |
| `^in` | reduction XOR | `^4'b1001` | `1'b0`，共有 2 個 `1`，even parity |
| `^~in` | reduction XNOR | `^~4'b1011` | `1'b0`，是 `^` 的反相 |
| `~^in` | reduction XNOR | `~^4'b1001` | `1'b1`，和 `^~` 同義 |

整組一起看：

```verilog
wire [3:0] a = 4'b1111;
wire [3:0] b = 4'b1011;
wire [3:0] c = 4'b0000;
wire [3:0] d = 4'b1001;

assign r_and   = &a;   // 1
assign r_nand  = ~&b;  // 1
assign r_or    = |b;   // 1
assign r_nor   = ~|c;  // 1
assign r_xor   = ^b;   // 1
assign r_xnor1 = ^~b;  // 0
assign r_xnor2 = ~^d;  // 1
```

- `^~in` 和 `~^in` 在 Verilog 都表示 reduction XNOR。

#### nor 、 nand ?

實際上 ~&B 和 ~|B 只是兩個一元運算分別運算而已，也就是先算 &B 再算 ~(&B)。

### Arithmetic / shift

```verilog
a + b
a - b
a * b
a << 2
a >> 1
```

- 先想 operand 位寬，再想結果要接到多寬的左值。
- carry 是否保留下來，不是只看 `+`，還要看結果位寬。

### Comparison

```verilog
a < b
a >= b
a == b
a != b
a === b
a !== b
```

- `==` / `!=`：一般 equality。
- `===` / `!==`：case equality，會把 `x/z` 一起比較。

## 快速對照

| 類型 | 例子 | 結果位寬 | 常見用途 |
| --- | --- | --- | --- |
| bitwise | `a & b` | 通常跟 operand 一樣寬 | 遮罩、逐 bit 邏輯 |
| logical | `a && b` | `1 bit` | 條件判斷 |
| reduction | `|bus` | `1 bit` | 任一位有效、全 1 判斷 |
| comparison | `a < b` | `1 bit` | 比大小、相等判斷 |

## 常見地雷

- 把 `|` 和 `||`、`&` 和 `&&` 混用。
- 以為 `a + b` 一定會自動多出一個 bit 保留 carry。
- 遇到 `x/z` 還用 `==` 判斷，結果和預期不同。
- 只看右邊運算式，忘了左邊接收位寬也會改變最後結果。
