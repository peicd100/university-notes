## bitwise 和 logical

一個會有完整的 n-bit，一個只會有 1 bit。

### 1\. bitwise operators

常見的有：  
\~：bitwise NOT  
&：bitwise AND  
|：bitwise OR  
^：bitwise XOR  
\~^ / ^\~：bitwise XNOR

bitwise 的特性

它會對每一個 bit 各自做運算。

例如：  
```verilog
assign y = a | b;
```

如果：  
```verilog
a = 4'b0101
b = 4'b0011
```

那結果就是逐位 OR：  
```verilog
y = 4'b0111
```

因為：  
```
0 | 0 = 0
1 | 0 = 1
0 | 1 = 1
1 | 1 = 1
```

### 2\. logical operators

常見的有：  
\!：logical NOT  
&&：logical AND  
||：logical OR。

logical 的特性：  
它不是逐 bit 算，而是把整個運算元當成布林值：  
非 0 → true  
0 → false  
然後輸出 1 bit 結果。HDLBits 的 Vectorgates 就是在強調這個 distinction。

### 3\. 最重要對照表

#### bitwise OR

```
a | b
```

逐 bit OR

輸出通常跟輸入一樣寬

例子：

```verilog
a = 3'b101
b = 3'b110
a | b = 3'b111
```

#### logical OR

```
a || b
```

把 a 和 b 整體當真假

輸出永遠是 1 bit

例子：

```verilog
a = 3'b101   // true
b = 3'b110   // true
a || b = 1'b1
```

### 4\. 執行 bitwise operators 位元不同時

```verilog
assign C = A\&B;
```
A、B 的高位補/截掉，直到和 C 一樣，再進行運算。

程式：  
```verilog
wire [2:0]A = 3’b011;
wire [4:0]B = 5’b10011;
wire [3:0]C = 4’b1011;
assign C = A & B; // C = 4'b0011
```

首先A和B會對齊  
A   00011  
```
B & 10011
-------
```
    00011

接著計算  
```verilog
A & B = 5'b00011
```

最後和 C 對齊  
```verilog
C = 4'b0011
```

### 5\. bitwise 偷懶方法

```
\&in = in[0]\&in[1]\&in[2]\&in[3]
```
注意，前面的只要寫變數名稱就好。  
你真的要寫 \&in\[3:0\] 也可以，因為 \&in 和 \&in\[3:0\] 其實是一樣的意思。

要注意！ 不適用於 logical ，也就是說不能寫 &\&in ，因為 && 是二元運算子，一定要有左右兩邊。

```verilog
\&in   // 等同 in[3] & in[2] & in[1] & in[0]
|in   // 等同 in[3] | in[2] | in[1] | in[0]
^in   // 等同 in[3] ^ in[2] ^ in[1] ^ in[0]

assign out_and = \&in;	//out_and = in[0]\&in[1]\&in[2]\&in[3];
assign out_or = |in;		//out_or = in[0]|in[1]|in[2]|in[3];
assign out_xor = ^in;	//out_xor = in[0]^in[1]^in[2]^in[3];
```

## 四則運算


進行四則運算時，結果位寬是 max(L(i), L(j))
如果是指派給某個變數時，根據左邊來算。

實際上真正影響的有：


值(value)
「這題數學答案是多少？」

位寬(bit width)
「我有幾個 bit 的空間可以裝答案？」

signed/unsigned
「我拿到這串 bit 後，要把它看成可正可負，還是只能當正數？」

### 值

這個式子在十進位會算出什麼？

1 + 1 = 2
5 - 8 = -3
5 / 2 = 1.5

### 位寬

位寬是 max(L(i), L(j)) ，如果是很多運算符號串在一起，就是看運算符號中 L(max_element()) 。

當
```v
wire [3:0] a, b; 
```
時

如果運算 a + b ，此時 a + b 是 4 bit。


如果有給左邊，就是根據左邊：

```v
wire [3:0] a, b; 
reg [15:0] sumA;
reg [16:0] sumB;
sumA = a + b;   // 用 16 bits 評估
sumB = a + b;   // 用 17 bits 評估
```

也就是說，位寬不是永遠只看右邊，還要看你最後把它塞進哪個盒子。





### signed / unsigned

如果任何 operand 是 real，結果就是 real。
否則只要任何 operand 是 unsigned，結果就是 unsigned。
只有當所有 operands 都是 signed，結果才是 signed。

#### real
這個值本身就是 real number(實數)。
real 轉 integer 是四捨五入到最近整數；剛好 .5 時，遠離 0。例如：
35.5 -> 36
1.5 -> 2
-1.5 -> -2


#### unsigned
無號數

#### signed
有號數
