## Verilog 數值規格

### 基本格式

```verilog
[size]'[base][value]
```

- `size`：位寬
- `base`：進位制
  - `b`：binary(二進位)
  - `d`：decimal(十進位)
  - `h`：hexadecimal(十六進位)
  - `o`：octal(八進位)
- `value`：數值內容

例如：

```verilog
8'b00001011
8'd11
8'h0B
8'o13
```

### 底線規格

- 數字中可以加 `_`
- `_` 只影響可讀性
- `_` 不影響數值
- `_` 不能放在數值開頭

例如：

```verilog
8'b0000_1011
```

### 零的寫法

下面都合法：

```verilog
0
1'b0
4'd0
4'b0000
```

### 直接寫整數的規格

```verilog
assign a = 5;
```

- 合法
- `5` 是 unsized decimal literal(未指定位寬的十進位常數)
- 位寬至少 32 bits
- 一般整數常值預設是 signed(有號)
- 有 base 的 literal 預設是 unsigned(無號)，除非加 `s`

### 指定位寬後的規格

當你寫了 `[size]`：

- 位數不夠：左邊補 0
- 位數太多：高位截掉
- 若最左位是 `x` 或 `z`，則向左延伸 `x` 或 `z`

例如：

```verilog
6'd11   // 6'b001011
2'd11   // 2'b11
```

### signed 寫法

格式：

```verilog
[size]'s[base][value]
```

例如：

```verilog
8'sd5
4'sb1010
16'shFF00
```

### 負數寫法

下面都合法：

```verilog
-1
-5
8'sd-3
```

### x、z 規格

在 based literal 中可使用：

- `x` / `X`：unknown(未知)
- `z` / `Z`：high impedance(高阻抗)
- `?`：等同於 `z`

例如：

```verilog
4'b10x1
4'bzz01
4'b1?0?
```

### 指派到較小位寬變數

例如：

```verilog
wire [3:0] a;
assign a = 5;
```

合法，結果等同於：

```verilog
assign a = 4'b0101;
```

### 建議寫法

優先寫成明確位寬：

```verilog
4'd5
8'b00001011
16'h00FF
1'b0
```

不要優先寫：

```verilog
5
0
11
```

### 速記結論

```verilog
0          // 可以直接寫
1'b0       // 可以
4'd5       // 最推薦
5          // 合法，但沒寫位寬
8'h0B      // 合法
6'd11      // 不夠位數補 0
2'd11      // 太多位數截掉高位
8'sd-3     // signed 寫法
4'b10x1    // x 合法
4'bzz01    // z 合法
