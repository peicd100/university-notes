# 數值與 Literal

## 一句話先懂

Verilog 的常數最常見格式是 `[size]'[base][digits]`，像 `8'b0000_1011`；位寬、進位、signedness 都會影響最後的結果。

## 核心規則

- 基本格式：`[size]'[base][digits]`
- 常見 base：
  - `b`：binary
  - `o`：octal
  - `d`：decimal
  - `h`：hex
- `_` 只影響可讀性，不影響數值。
- 可以用 `s` 表示 signed，例如 `8'sd-3`。
- `x` 代表 unknown，`z` 代表 high-impedance。
- 指派到較寬變數時會延伸，指派到較窄變數時會截斷。

## 常用模板或例子

### 基本寫法

```verilog
8'b0000_1011
8'd11
8'h0B
8'o13
```

### 零與一般整數

```verilog
0
1'b0
4'd0
4'b0000
```

```verilog
assign a = 5;
```

- 直接寫 `5` 也是合法的常數。
- 但未指定位寬時，常常會讓位寬與 signedness 判斷變得不夠直觀。

### signed 寫法

```verilog
8'sd-3
4'sb1101
```

- 有 signed 運算需求時，最好把型別與 literal 都寫清楚。

### `x` 與 `z`

```verilog
4'b10xz
8'bzzzz_zzzz
```

- `x` 常見於模擬未知值。
- `z` 常見於 tri-state bus。

### 位寬延伸與截斷

```verilog
wire [7:0] a;
wire [3:0] b;

assign a = 4'b1010;
assign b = 8'hAB;
```

- `a = 4'b1010`：較窄常數被延伸到 8 bit。
- `b = 8'hAB`：只會留下低 4 bit。

## 建議寫法

- 能寫明確位寬時，就不要偷懶只寫裸整數。
- 算術、比較、signed 運算時，最好把位寬一起寫清楚。
- 需要 sign extension 時，寧可自己用串接明確寫出來。

## 常見地雷

- 以為 `5` 和 `4'd5` 在所有情況下都完全一樣。
- 沒有弄清楚 signed / unsigned，就直接做比較或加減。
- 忽略 `x/z` 會影響比較與 pattern matching。
- 位寬不一致時，沒先想清楚會補位還是截斷。
