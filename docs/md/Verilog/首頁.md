# Verilog Quick Reference

## 一句話先懂

這一區把 Verilog 筆記整理成「主題清楚、重複最少、查找很快」的速查筆記。  
每一頁只處理一個主題，觀念重疊時改用相對連結，不再把同一件事散落在很多頁重講。

## 主題地圖

### 基礎語法

- [模組與建模方式](模組與建模方式.md)：module、port、`assign`、三種建模風格。
- [常見資料型別](常見資料型別.md)：`wire`、`reg`、`integer`、port 宣告。
- [Vector、MSB 與 LSB](vector.md)：位寬、方向、切片、串接、replication。
- [數值與 Literal](數值.md)：`8'b1010`、signed、`x/z`、extend/truncate。
- [運算子](運算子.md)：bitwise、logical、reduction、arithmetic、comparison。

### 程序式寫法

- [always、initial 與事件控制](always、initial 與事件控制.md)：組合邏輯、時序邏輯、`@*`、`posedge`、latch。
- [blocking 與 non-blocking](blocking 與 non-blocking.md)：`=` 和 `<=` 的語意與實務用法。
- [選擇結構](選擇結構.md)：`if`、`?:`、`case`、`casez`、`casex`。
- [迴圈與程序控制](迴圈與程序控制.md)：`for`、`repeat`、`while`、`forever`、`wait`、`fork...join`。

### 模擬與常見電路

- [模擬控制與 System Tasks](system tasks.md)：``timescale`、`#delay`、`$display`、`$monitor`、`$finish`。
- [Priority Encoder](priority encoder.md)：priority 方向、`casez`、`valid`、常見地雷。

## 使用方式

- 先從這頁找主題，不確定分類時優先看「主題地圖」。
- 遇到 `always @(*)`、latch、`=` / `<=` 這類常一起出現的觀念，照頁面底部的「相關主題」繼續看。
- 如果你是在刷 HDLBits 或寫實驗作業，建議把這區和 [Verilog 學習資源整理](學習資源整理.md) 一起用。
