## module

### 兩種寫 input 和 output 的方式

```verilog
module f1(  
    input a,b,  
    output c,d  
);  
    assign c = a & b;  
    assign d = a | b;  
endmodule
```

```verilog
module f2(a,b,c,d);  
    input a,b;  
    output c,d;  
     
    assign c = a & b;  
    assign d = a | b;  
endmodule
```

## primitive

直接寫 true table 的電路模組，可以有多個 input ，但是 output 只能有一個，而且定義時要放最前面。

```v
primitive p(
    output z,  		//第一個只能放 output ，而且 output 只能有一個。
    input x,y
    );
    table
        0 0  : 0;  // x y : z;
        0 1  : 1;
        1 0  : 0;
        1 1  : 0;
    endtable
endprimitive
```
