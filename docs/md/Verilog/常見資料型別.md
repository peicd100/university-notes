# 常見資料型別

## 一句話先懂

入門 Verilog 最常用到的型別先記三個就夠了：  
`wire`、`reg`、`integer`。

## 核心規則

- `wire` 是 net，代表「被持續驅動的連線」。
- `reg` 是 variable，代表「可在 `always` / `initial` 中被賦值的變數」。
- `integer` 常用在 `for` 迴圈索引、計數或 testbench 暫存整數。
- `reg` 不等於實體暫存器；它最後是不是 flip-flop、latch 或組合邏輯，要看寫法。
- `output` 預設是 `wire`；如果它要在 `always` 裡被賦值，就要寫成 `output reg`。

## 常用模板或例子

### `wire`

```verilog
wire y;
assign y = a & b;
```

- 適合 `assign` 左邊。
- 也常用來接子模組輸出與中介連線。

### `reg`

```verilog
reg y;

always @(*) begin
    y = a & b;
end
```

- 適合程序式賦值。
- 可用在組合 `always @(*)`，也可用在時序 `always @(posedge clk)`。

### `integer`

```verilog
integer i;

always @(*) begin
    for (i = 0; i < 8; i = i + 1)
        y[i] = a[i] & b[i];
end
```

- 常用在 loop index。
- 不建議拿來當一般固定寬度資料路徑訊號。

對 module 裡宣告的 `integer i;` 來說，不是「module 執行完就把 i 丟掉」。
更精確地說：
* `module` 不是像 C++ 函式那樣「呼叫一次、跑完、結束、釋放區域變數」的東西。  
* 在 Verilog/SystemVerilog 裡，module 內宣告的變數通常是 **static lifetime(靜態生命週期)**，也就是它會在整個模擬期間都存在，不是每次 `always` 跑完就消失。


### Port 宣告

```verilog
module example (
    input  wire       a,
    input  wire [7:0] data_in,
    output wire       y1,
    output reg  [7:0] y2,
    inout  wire [7:0] bus
);
    assign y1 = a;

    always @(*) begin
        y2 = data_in;
    end
endmodule
```

- `input` 預設可視為 `wire`。
- `output` 若在 `always` 內被指定，要改成 `output reg`。
- `inout` 常搭配 tri-state bus。

## 快速判斷

- `assign` 左邊：先想 `wire`
- `always` / `initial` 左邊：先想 `reg`
- `for (i = ...)` 的 `i`：先想 `integer`
- 固定寬度資料：用 `wire [N:0]` 或 `reg [N:0]`

## 常見地雷

- 把 `output` 留成預設 `wire`，卻在 `always` 內對它賦值。
- 認為 `reg` 一定綜合成 register。
- 用 `integer` 去取代明確位寬的硬體訊號。
- 把 `wire` 當成只能接很簡單的單 bit 訊號。
