## 數值

當在 verilog 表達 0 時，不能直接寫 0 ，要寫 1’b0。

```verilog
[size]'[base][value]
assign a = 8'b0000_1011
```
也就是 位寬 \+ 單引號 \+ 進位制 \+ 數值內容。這個格式是 Verilog 常見的數字寫法，例如二進位、十進位、八進位、十六進位都能這樣寫；而底線 \_ 只是為了可讀性，語意上會被忽略。

舉例：  
```verilog
8'b00001011   // 二進位
8'd11         // 十進位
8'h0B         // 十六進位
```

所以：  
```verilog
wire [3:0] v;
assign v = 4'd11;   // v = 1011
```

結論：  
4'd11 就是  
把 d11 轉為二進位，塞進 4 bit

且會遵守多的去掉，少的補0：  
```verilog
6'd11 = 6'b001011
2'd11 = 2'b11
```

## MSB、LSB

### MSB(Most Significant Bit)

最高有效位元，也就是最左邊的位元。

### LSB(Least Significant Bit)

最低有效位元，也就是最右邊的位元。

## bitwise 和 logical

一個會有完整的 n-bit，一個只會有 1 bit。

### 1\. bitwise operators

常見的有：  
\~：bitwise NOT  
&：bitwise AND  
|：bitwise OR  
^：bitwise XOR  
\~^ / ^\~：bitwise XNOR

bitwise 的特性

它會對每一個 bit 各自做運算。

例如：  
```verilog
assign y = a | b;
```

如果：  
```verilog
a = 4'b0101
b = 4'b0011
```

那結果就是逐位 OR：  
```verilog
y = 4'b0111
```

因為：  
```
0 | 0 = 0
1 | 0 = 1
0 | 1 = 1
1 | 1 = 1
```

### 2\. logical operators

常見的有：  
\!：logical NOT  
&&：logical AND  
||：logical OR。

logical 的特性：  
它不是逐 bit 算，而是把整個運算元當成布林值：  
非 0 → true  
0 → false  
然後輸出 1 bit 結果。HDLBits 的 Vectorgates 就是在強調這個 distinction。

### 3\. 最重要對照表

#### bitwise OR

```
a | b
```

逐 bit OR

輸出通常跟輸入一樣寬

例子：

```verilog
a = 3'b101
b = 3'b110
a | b = 3'b111
```

#### logical OR

```
a || b
```

把 a 和 b 整體當真假

輸出永遠是 1 bit

例子：

```verilog
a = 3'b101   // true
b = 3'b110   // true
a || b = 1'b1
```

### 4\. 執行 bitwise operators 位元不同時

```verilog
assign C = A\&B;
```
A、B 的高位補/截掉，直到和 C 一樣，再進行運算。

程式：  
```verilog
wire [2:0]A = 3’b011;
wire [4:0]B = 5’b10011;
wire [3:0]C = 4’b1011;
assign C = A & B; // C = 4'b0011
```

首先A和B會對齊  
A   00011  
```
B & 10011
-------
```
    00011

接著計算  
```verilog
A & B = 5'b00011
```

最後和 C 對齊  
```verilog
C = 4'b0011
```

### 5\. bitwise 偷懶方法

```
\&in = in[0]\&in[1]\&in[2]\&in[3]
```
注意，前面的只要寫變數名稱就好。  
你真的要寫 \&in\[3:0\] 也可以，因為 \&in 和 \&in\[3:0\] 其實是一樣的意思。

要注意！ 不適用於 logical ，也就是說不能寫 &\&in ，因為 && 是二元運算子，一定要有左右兩邊。

```verilog
\&in   // 等同 in[3] & in[2] & in[1] & in[0]
|in   // 等同 in[3] | in[2] | in[1] | in[0]
^in   // 等同 in[3] ^ in[2] ^ in[1] ^ in[0]

assign out_and = \&in;	//out_and = in[0]\&in[1]\&in[2]\&in[3];
assign out_or = |in;		//out_or = in[0]|in[1]|in[2]|in[3];
assign out_xor = ^in;	//out_xor = in[0]^in[1]^in[2]^in[3];
```
