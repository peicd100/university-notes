## 問題

請看以下程式碼([題目網址](https://hdlbits.01xz.net/wiki/Popcount3))。

```v
module top_module( 
    input [2:0] in,
    output reg [1:0] out );
    
    integer i,j=0;
    always @(*) begin 
        for(i=0;i<=2;i=i+1)begin
            j = j + in[i];
        end
        out = j;
    end
endmodule
```

這個電路目的是計算 in 有多少 bit 是 1 ，但是其實電路會有問題，會有 bug 。
因為第一次宣告 integer j=0; 時，他之後就不會再變成 0 了，因為 verilog 的變數不像是 C++ 出了函數之後就會被丟棄。也就是說會像是 C++ 的靜態(static)變數。

所以在 always 中要用到時，等於左邊的 reg(output reg) 或是 integer 盡量都先初始化(等於0)，這樣也可以[防止變成 latch](防止變成%20latch.md#組合邏輯電路變成-latch-的問題)。
