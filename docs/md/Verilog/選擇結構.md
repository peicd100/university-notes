# 選擇結構

## 一句話先懂

Verilog 最常用的選擇結構是 `if / else`、`?:`、`case`。  
先看你要的是「有優先順序的判斷」還是「固定值多選一」，再選語法。

## 核心規則

- `if / else if / else`：最適合有先後優先權的條件判斷。
- `?:`：最適合短小的單行 mux。
- `case`：最適合固定值多選一。
- `casez`：當 `z` 或 `?` 要當 wildcard 時使用。
- `casex`：會把 `x` 也當成 wildcard，一般 RTL 不建議常規使用。

## 常用模板或例子

### `if / else`

```verilog
always @(*) begin
    grant = 2'b00;

    if (req2)
        grant = 2'b10;
    else if (req1)
        grant = 2'b01;
end
```

- `else if` 本身就帶有 priority。

### `?:`

```verilog
assign out = sel ? b : a;
```

- 簡單、短小、很適合 2-to-1 mux。
- 層數太多就不建議一直巢狀下去。

### `case`

```verilog
always @(*) begin
    out = 2'b00;

    case (sel)
        2'b00: out = a;
        2'b01: out = b;
        2'b10: out = c;
        default: out = d;
    endcase
end
```

- 適合 mutually exclusive 的固定值判斷。
- 組合邏輯時，最好搭配 `default` 或先給預設值。

### `casez`

```verilog
always @(*) begin
    out = 2'b00;

    casez (in)
        4'b1???: out = 2'd3;
        4'b01??: out = 2'd2;
        4'b001?: out = 2'd1;
        4'b0001: out = 2'd0;
        default: out = 2'd0;
    endcase
end
```

- 適合 pattern matching。
- 若 pattern 有重疊，分支順序就會變重要。

### `casex`

```verilog
casex (in)
    4'b1xxx: out = 2'd3;
    default: out = 2'd0;
endcase
```

- 語法合法，但因為 `x` 也會被吞成 wildcard，容易掩蓋 bug。
- 一般 RTL 寫作，優先考慮 `case` 或 `casez`。

## 怎麼挑

- 有優先權：`if / else if`
- 很短的一行 mux：`?:`
- 固定值多選一：`case`
- 真的需要 wildcard：`casez`
- 常規 RTL：盡量不要把 `casex` 當主力

如果你是在寫 priority encoder，請直接看 [Priority Encoder](priority encoder.md)。

## 常見地雷

- 組合邏輯忘記先給預設值，或忘記 `default`。
- `casez` 分支有重疊，卻沒注意順序。
- `?:` 一路巢狀下去，最後自己也看不懂。
- 把 `casex` 用在常規 RTL，讓 `x` 問題被藏起來。
