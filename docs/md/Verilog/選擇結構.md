Verilog 裡的選擇結構，常見可以分成這幾類：

1. if / else if / else
2. ?: conditional ternary operator（條件運算子）
3. case
4. casez
5. casex




## `if / else if / else`

### 語法格式

```verilog
if (condition_1)
    statement_1;
else if (condition_2)
    statement_2;
else
    statement_default;
```

多句版本：

```verilog
if (condition_1) begin
    ...
end
else if (condition_2) begin
    ...
end
else begin
    ...
end
```

### 每個位置放什麼

* `condition`：放 expression，最後會被判斷成 true/false
* `statement`：一個 procedural statement，或 `begin...end`

### 常見資料型態

* `condition` 常是 `wire/reg` 或比較運算結果
* 被指定的左值通常是 `reg`
* 右值可為 `wire/reg/constant/expression`

### 常見用途

* 2-to-1 mux
* priority logic(優先邏輯)
* reset / enable 控制
* 範圍判斷

### 它對應什麼硬體

* 在 `always @(*)` 裡，常綜合成 mux 或 priority logic
* 在 `always @(posedge clk)` 裡，常綜合成帶 reset / enable 的 flip-flop 結構

### 常用技巧

#### 技巧 1：有優先權才用 `else if`

```verilog
always @(*) begin
    if (req2)
        grant = 2'b10;
    else if (req1)
        grant = 2'b01;
    else
        grant = 2'b00;
end
```

#### 技巧 2：組合邏輯先給預設值

```verilog
always @(*) begin
    grant = 2'b00;

    if (req2)
        grant = 2'b10;
    else if (req1)
        grant = 2'b01;
end
```

#### 技巧 3：固定值很多時改用 `case`

如果條件都長得像 `sel == 2'b00`、`sel == 2'b01`，通常 `case` 更好讀。([ChipVerify][5])

### 好看好用的寫法

* `if / else if / else` 垂直對齊
* 條件由高優先到低優先排序
* 分支多行就加 `begin...end`

### 常見地雷

* Verilog **沒有 `elif`**，只有 `else if`
* 在組合邏輯裡漏掉 `else` 或預設值，可能推導出 latch。Nandland 明確提醒不完整賦值會造成 latch。([Nandland][6])

## `?:` conditional ternary operator（條件運算子）

這就是你很常看到的單行寫法。

```verilog
assign out = sel ? b : a;
```

也可以巢狀：

```verilog
assign out = (sel == 2'd0) ? a :
             (sel == 2'd1) ? b :
             (sel == 2'd2) ? c : d;
```

也可以連在一起：


```v
assign min = (((a<b)?a:b)<((c<d)?c:d)) ? ((a<b)?a:b) : ((c<d)?c:d);
```

### 適合什麼？

* 2-to-1 mux
* 短小的組合邏輯選擇
* 想用 `assign` 一行解決時

### C++ 對照

```cpp
out = sel ? b : a;
```

### 重點

簡潔，但如果你寫太多層巢狀，可讀性會變差。
簡單選擇很好用，複雜選擇通常還是 `if` 或 `case` 比較清楚。

## `case`

### 語法格式

```verilog
case (expr)
    item_1: statement_1;
    item_2: statement_2;
    ...
    default: statement_default;
endcase
```

多句版本：

```verilog
case (expr)
    item_1: begin
        ...
    end
    default: begin
        ...
    end
endcase
```

### 每個位置放什麼

* `expr`：被比較的 expression，例如 `sel`、`state`
* `item_n`：常數或常數樣式
* `statement_n`：一個 statement 或 `begin...end`

### 常見資料型態

* `expr` 常是 scalar 或 vector
* `item_n` 常寫成對應寬度的常數，如 `2'b00`
* 左值通常是 `reg`

### 常見用途

* 多工器 mux
* decoder
* FSM 狀態分支

### 常用技巧

#### 技巧 1：固定值多選一時，優先 `case`

```verilog
always @(*) begin
    case (sel)
        2'b00: out = in0;
        2'b01: out = in1;
        2'b10: out = in2;
        2'b11: out = in3;
        default: out = 8'b0;
    endcase
end
```

#### 技巧 2：先給預設值，後 `case`

```verilog
always @(*) begin
    out = 8'b0;

    case (sel)
        2'b00: out = in0;
        2'b01: out = in1;
        2'b10: out = in2;
        2'b11: out = in3;
    endcase
end
```

#### 技巧 3：常數格式統一

都寫 `2'b00`、`2'b01`，不要混著寫 `0`、`1`、`2'b10`。

### 好看好用的寫法

* `case (expr)` 自己一行
* 所有 item 冒號對齊
* 分支很多時按數值順序或邏輯順序排列

### 常見地雷

* 漏 `default` 或漏預設值，組合邏輯仍可能做出 latch。([Nandland][6])
* case item 內有多句卻忘了 `begin...end`

## `casez`

這是 `case` 的加強版，允許你把 `z` 或 `?` 當作 don’t care（不在乎）來匹配。

```verilog
always @(*) begin
    casez (in)
        4'b1???: out = 2'd3;
        4'b01??: out = 2'd2;
        4'b001?: out = 2'd1;
        4'b0001: out = 2'd0;
        default: out = 2'd0;
    endcase
end
```

### 這在做什麼？

例如 `4'b1???` 的意思是：

* 第一位一定要是 `1`
* 後三位隨便

所以它很適合寫：

* priority encoder（優先編碼器）
* 某些 pattern matching（樣式匹配）

### 重點

* `casez` 會把 `Z` 和 `?` 視為 wildcard（萬用字元）
* 若有多個 case item 都能匹配，**第一個匹配到的優先**
* 所以它其實也能做出 priority 邏輯([verilogpro.com][2])

### 但要小心

`casez` 很方便，但如果輸入某一位剛好是未接好、飄成 `Z`，也可能被你當成合法匹配，進而**掩蓋 bug**。所以能用時通常建議：

* 明確知道你在做 wildcard matching
* 常用 `?` 來表示 don’t care，比直接寫 `z` 更清楚([verilogpro.com][2])

## `casex`

這比 `casez` 更鬆，因為它把：

* `Z`
* `?`
* `X`

都當成 don’t care。

```verilog
casex (in)
    4'b1xxx: out = 1'b1;
    default: out = 1'b0;
endcase
```

### 問題在哪？

`X` 在模擬裡常常代表：

* 未初始化
* 衝突
* 不確定值

如果你把 `X` 也當成 don’t care，很多本來應該暴露的錯誤就被吞掉了。

### 結論

**合成用 RTL 一般不建議用 `casex`。** 這點是業界很常見的建議。([verilogpro.com][2])
