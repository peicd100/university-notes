# system tasks（系統任務）

可以，我幫你整理成**最適合寫在筆記 / 實驗報告**的短版。

---

## $display

**一句話介紹：** 在執行到該行時，**立即印出一次**指定內容，並自動換行。  
**範例：**

initial begin

    a \= 0; b \= 1;

    $display("a=%b b=%b", a, b);

end

**可能輸出：**

a=0 b=1

---

## $monitor

**一句話介紹：** 先設定一個監看器，之後只要參數中的**任一值改變**，就會**自動印出一行最新結果**。

**範例：**

initial begin

    $monitor("time=%0t a=%b b=%b", $time, a, b);

    a \= 0; b \= 0;

    \#10 a \= 1;

    \#10 b \= 1;

end

**可能輸出：**

time=0 a=0 b=0

time=10 a=1 b=0

time=20 a=1 b=1

---

## $finish

**一句話介紹：** 在執行到該行時，**正式結束整個模擬**。  
**範例：**

initial begin

    a \= 0; b \= 0;

    \#10 a \= 1;

    \#10 $finish;

end

**效果：** 模擬會在指定時間點結束，不再繼續跑。

---

## 你可以直接這樣記

$display  \-\> 到這一行時印一次

$monitor  \-\> 之後有變化就自動印

$finish   \-\> 結束模擬

---

## 跟這堂課的關係

這三個都是 **testbench（測試平台）** 最基本的工具：

* `$display`：看某一刻的值  
* `$monitor`：持續追蹤變化  
* `$finish`：測完收尾

也就是說，它們不是在「做硬體功能」，而是在幫我們**驗證硬體有沒有寫對**。這就是你這門課從「寫電路」走到「驗證電路」最核心的一步。
