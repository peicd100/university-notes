# Verilog 學習資源整理

## 一句話先懂

如果你要把 Verilog 學穩，最有效的順序通常是：  
先用題目練手，再用教程補語法，最後用課程或書把整體設計流程接起來。

## 最短學習路線

1. 先刷 [HDLBits](https://hdlbits.01xz.net/wiki/Main_Page) 練語法與小題。
2. 卡觀念時回來查本區主題筆記，或看 [ChipVerify Verilog](https://www.chipverify.com/verilog/verilog-quick-refresher)。
3. 需要白話講解時看 [Nandland Learn Verilog](https://nandland.com/learn-verilog/) 或中文課程。
4. 想驗證小例子時用 [EDA Playground](https://www.edaplayground.com/)。

## 刷題與實作

### HDLBits

- 定位：刷題主線。
- 優點：從 basic 到 sequential 逐步加深，交題後可立即驗證。
- 適合：剛開始學、要把 `module`、`vector`、組合/時序邏輯寫熟的人。

### EDA Playground

- 定位：線上即寫即跑。
- 優點：快速驗證 testbench、波形、`always` 行為與小型語法實驗。
- 適合：想把疑問變成最小可重現例子的人。

## 查語法與風格

### ChipVerify Verilog

- 連結：[ChipVerify Verilog](https://www.chipverify.com/verilog/verilog-quick-refresher)
- 定位：文字式主教材與 reference。
- 優點：模組、data types、operators、always block、assignments 等主題都整理得很完整。

### Nandland Learn Verilog

- 連結：[Nandland Learn Verilog](https://nandland.com/learn-verilog/)
- 定位：入門到中階、偏 FPGA 實作。
- 優點：對 `blocking/non-blocking`、latch、for loop、clocked logic 這些實務風格提醒很直接。

### ASIC-World Verilog Tutorial

- 連結：[ASIC-World Verilog Tutorial](https://www.asic-world.com/verilog/veritut.html)
- 定位：老牌大全型字典。
- 優點：需要快速查 system task、testbench、FSM 或少見語法時很好用。

## 課程與書

### 清大 OCW 數位邏輯設計

- 連結：[清大 OCW](https://ocw.nthu.edu.tw/ocw/index.php?cid=230&id=1023&page=course_news_content)
- 定位：學院派完整脈絡。
- 適合：想把數位邏輯、Verilog 與 FPGA/ASIC 流程連起來的人。

### Coursera FPGA HDL 課程

- 連結：[Coursera HDL 課程](https://www.coursera.org/learn/fpga-hardware-description-languages)
- 定位：有節奏的課程型學習。
- 適合：需要作業與測驗推著學的人。

### Verilog HDL: A Guide to Digital Design and Synthesis

- 連結：[Amazon 書籍頁](https://www.amazon.com/Verilog-HDL-2nd-Samir-Palnitkar/dp/0130449113)
- 定位：經典工具書。
- 適合：想系統化補齊語意細節、可綜合注意事項的人。

### Digital Design and Computer Architecture

- 連結：[天瓏介紹頁](https://www.tenlong.com.tw/products/9780123944245)
- 定位：把 Verilog 放進整體系統設計脈絡。
- 適合：不只想會語法，也想理解 CPU/系統怎麼長出來的人。
