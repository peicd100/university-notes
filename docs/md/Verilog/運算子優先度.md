# 運算子優先度

## 總表

```v
1.  +(正)  -(負，乘上-1)  !  ~  &  ~&  |  ~|  ^  ~^  ^~    //一元運算子
2.  **                                      //次方，如 2**10 = 1024
3.  *  /  %                                 //乘、除、餘數
4.  +  -                                    //二元運算子
5.  <<  >>  <<<  >>>                        //位元移動
6.  <  <=  >  >=                            //比較
7.  ==  !=  ===  !==                        //相等
8.  &        (binary bitwise AND)           //一(字)元乘
9.  ^  ^~  ~^ (binary bitwise XOR/XNOR)     
10. |        (binary bitwise OR)            //一(字)元加
11. &&                                      //兩(字)元乘
12. ||                                      //兩(字)元加
13. ?:                                      //三元運算子
14. {}  {{}}  // concatenation, replication，最低
```

##  簡化規律

1. 先一元，再二元，再三元運算
2. 先乘除後加減(這些是二元運算)
3. &、| 比照"先乘除後加減"，& 是乘，| 是加。
