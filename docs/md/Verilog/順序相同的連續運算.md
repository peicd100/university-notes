請看這題：https://hdlbits.01xz.net/wiki/Gatesv100

這題簡單來說就是

out_both[i] = in[i] & in[i+1];

out_any[i] = in[i] | in[i-1];

out_different[i] = in[i] != in[i+1];
...
out_different[99] = in[99]!= in[0];

要怎麼寫程式碼呢？

有以下兩種寫法
/// collapse-code  
```v title = "第一種"
module top_module( 
    input [99:0] in,
    output reg [98:0] out_both,
    output reg [99:1] out_any,
    output reg [99:0] out_different );
    integer i;

    always @(*)begin

        for(i=0;i<=98;i=i+1)begin
            out_both[i] = in[i] & in[i+1];
        end

        for(i=1;i<=99;i=i+1)begin
            out_any[i] = in[i] | in[i-1];
        end 

        for(i=0;i<=98;i=i+1)begin
            out_different[i] = in[i] != in[i+1];
        end 
        out_different[99] = in[99]!= in[0];


    end
endmodule
```
///
/// collapse-code  
```v title = "第二種"
module top_module( 
    input [99:0] in,
    output [98:0] out_both,
    output [99:1] out_any,
    output [99:0] out_different );
    
    genvar i;
    generate
        for(i=0;i<=98;i=i+1)begin : g1
            assign out_both[i] = in[i] & in[i+1];
        end
        
        for(i=1;i<=99;i=i+1)begin : g2
            assign out_any[i] = in[i] | in[i-1];
        end 
        
        for(i=0;i<=99;i=i+1)begin : g3
            if(i==99) assign out_different[99] = in[99]!= in[0];
            else assign out_different[i] = in[i] != in[i+1];
        end 
    endgenerate
endmodule
```
///

```v title = "第三種"
module top_module( 
    input [99:0] in,
    output [98:0] out_both,
    output [99:1] out_any,
    output [99:0] out_different );

    assign out_both      = in[98:0] & in[99:1];
    assign out_any       = in[99:1] | in[98:0];
    assign out_different = in ^ {in[0], in[99:1]};

endmodule
```

哪一種比較簡單 ？

顯然是第三種比較方便。為何可以這樣寫呢？，因為等於的左右兩邊順序相同，其實
```
assign out_both      = in[98:0] & in[99:1];
```
就是
```
assign out_both [99:0]     = in[98:0] & in[99:1];
```
所以全部都能對齊，然後 & 是對於左右兩邊的每一個 bit 運算，便能夠答道題目要求。

不過這有一個限制，就是 vector 的方向要一樣。

這邊也可以看到一個重點：`^`可以當不等於。那問題來了，啥符號可以當等於？
就是 `~^` ，其實就是不等於的相反啦。
