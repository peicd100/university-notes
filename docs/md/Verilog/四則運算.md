
## 四則運算


進行四則運算時，結果位寬是 max(L(i), L(j))
如果是指派給某個變數時，根據左邊來算。

實際上真正影響的有：


值(value)
「這題數學答案是多少？」

位寬(bit width)
「我有幾個 bit 的空間可以裝答案？」

signed/unsigned
「我拿到這串 bit 後，要把它看成可正可負，還是只能當正數？」

### 值

這個式子在十進位會算出什麼？

1 + 1 = 2
5 - 8 = -3
5 / 2 = 1.5

### 位寬

位寬是 max(L(i), L(j)) ，如果是很多運算符號串在一起，就是看運算符號中 L(max_element()) 。

當
```v
wire [3:0] a, b; 
```
時

如果運算 a + b ，此時 a + b 是 4 bit。


如果有給左邊，就是根據左邊：

```v
wire [3:0] a, b; 
reg [15:0] sumA;
reg [16:0] sumB;
sumA = a + b;   // 用 16 bits 評估
sumB = a + b;   // 用 17 bits 評估
```

也就是說，位寬不是永遠只看右邊，還要看你最後把它塞進哪個盒子。





### signed / unsigned

如果任何 operand 是 real，結果就是 real。
否則只要任何 operand 是 unsigned，結果就是 unsigned。
只有當所有 operands 都是 signed，結果才是 signed。

#### real
這個值本身就是 real number(實數)。
real 轉 integer 是四捨五入到最近整數；剛好 .5 時，遠離 0。例如：
35.5 -> 36
1.5 -> 2
-1.5 -> -2


#### unsigned
無號數

#### signed
有號數
