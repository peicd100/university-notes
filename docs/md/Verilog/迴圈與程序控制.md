# 迴圈與程序控制

## 一句話先懂

Verilog 的 `for`、`repeat`、`while`、`forever`、`wait`、`fork...join` 都是程序式敘述；但不是每一個都適合拿來當可綜合 RTL 主力。

## 核心規則

- `for`：RTL 最常用的迴圈，常被展開成重複硬體。
- `repeat`：重複固定次數，偏模擬常用。
- `while`：偏 testbench，綜合彈性較差。
- `forever`：無窮迴圈，常用在 clock generator。
- `wait`：等條件成立再往下。
- `fork...join`：平行執行多個程序，偏 testbench。
- `disable`：離開 named block 或 task。

## 常用模板或例子

### `for`，可綜合常用

```verilog
integer i;

always @(*) begin
    for (i = 0; i < 8; i = i + 1)
        y[i] = a[i] & b[i];
end
```

- 最常見於 bit-slice 處理、array 初始化、重複結構。
- 上界最好是常數或 parameter。

### `repeat`，偏 testbench

```verilog
initial begin
    repeat (4) @(posedge clk);
    done = 1'b1;
end
```

### `while`，偏 testbench

```verilog
initial begin
    while (!done)
        @(posedge clk);
end
```

- 迭代次數不夠靜態明確時，不適合當一般 RTL 主力。

### `forever`，偏 testbench

```verilog
initial begin
    clk = 1'b0;
    forever #5 clk = ~clk;
end
```

- 最經典用途就是時脈產生器。

### `wait`，偏 testbench

```verilog
initial begin
    wait (ready);
    start = 1'b1;
end
```

### `fork ... join`，偏 testbench

```verilog
initial begin
    fork
        begin
            #10 a = 1'b1;
        end
        begin
            #20 b = 1'b1;
        end
    join
end
```

### `disable`

```verilog
initial begin : main_block
    if (error)
        disable main_block;
end
```

## 快速判斷

- RTL 常用：`for`
- 模擬常用：`repeat`、`while`、`forever`、`wait`、`fork...join`、`disable`

## 常見地雷

- 把 `for` 想成軟體迴圈，忘了它在 RTL 常代表「空間上的重複硬體」。
- `while` 或 `forever` 沒有事件控制 / delay，模擬直接卡住。
- `fork...join` 用進 RTL 思維，讓流程變得難讀又難驗證。
- `for` 上界不是靜態可判斷的值，導致綜合不穩。
