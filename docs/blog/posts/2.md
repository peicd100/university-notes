# 測試

<!-- more -->


可以，以下我把你剛剛那幾張投影片中的**例題**，整理成「**題目**＋**解答**」版本，方便你之後直接複習或抄筆記。

這些題目的核心都建立在同一組公式上：

* **CPU Time = Instruction Count × CPI × Clock Cycle Time**
* **CPU Time = Clock Cycles / Clock Rate**
* **Performance ∝ 1 / Execution Time**

這些都是經典的計算機結構效能公式。([EECS Berkeley][1])

---

### 題目 1：相對效能(Relative Performance，相對效能)

**題目：**
如果計算機 A 執行一個程式需時 **10 秒**，而計算機 B 執行相同程式需時 **15 秒**，則 **A 比 B 快幾倍**？

**解答：**

相對效能公式：

\[
\frac{Performance_A}{Performance_B}=\frac{Execution\ Time_B}{Execution\ Time_A}
\]

代入數值：

[
\frac{Performance_A}{Performance_B}=\frac{15}{10}=1.5
]

**答案：A 比 B 快 1.5 倍。**

---

### 題目 2：使用效能計算式(Performance Equation，效能計算式)

**題目：**
假設我們有對於同一個 ISA(instruction set architecture，指令集架構) 的兩種實作方式。

* 計算機 A 的 **clock cycle time(時脈週期)** 為 **250 ps**
* 計算機 A 對某程式的 **CPI** 為 **2.0**
* 計算機 B 的 **clock cycle time** 為 **500 ps**
* 計算機 B 對同一程式的 **CPI** 為 **1.2**

問：**哪一台計算機較快？快多少？**

**解答：**

設該程式的 **instruction count(指令數)** 為 (I)

CPU 時間公式：

[
CPU\ Time = Instruction\ Count \times CPI \times Clock\ Cycle\ Time
]

#### 計算 A 的 CPU 時間

[
CPU\ Time_A = I \times 2.0 \times 250ps = 500I\ ps
]

#### 計算 B 的 CPU 時間

[
CPU\ Time_B = I \times 1.2 \times 500ps = 600I\ ps
]

因為：

[
500I\ ps < 600I\ ps
]

所以 **A 比 B 快**。

快多少倍：

[
\frac{Performance_A}{Performance_B}
===================================

# \frac{Execution\ Time_B}{Execution\ Time_A}

# \frac{600I}{500I}

1.2
]

**答案：計算機 A 較快，且 A 是 B 的 1.2 倍快。**

### 題目 3：改善效能(Improving Performance，改善效能)

**題目：**
某程式在計算機 A 上執行需時 **10 秒**，其 **clock rate(時脈速度)** 為 **2 GHz**。
現在要設計另一台計算機 B，希望它可以在 **6 秒** 內執行相同程式。

已知因為設計改變，B 執行該程式時需要 **A 的 1.2 倍 clock cycles(時脈數)**。

問：**計算機 B 的目標 clock rate 應該是多少？**

**解答：**

先算 A 的總時脈數：

[
CPU\ Time_A = \frac{Clock\ Cycles_A}{Clock\ Rate_A}
]

代入：

[
10 = \frac{Clock\ Cycles_A}{2 \times 10^9}
]

所以：

[
Clock\ Cycles_A = 10 \times 2 \times 10^9 = 20 \times 10^9
]

B 需要 1.2 倍時脈數，所以：

[
Clock\ Cycles_B = 1.2 \times 20 \times 10^9 = 24 \times 10^9
]

又因為 B 要在 6 秒內完成：

[
6 = \frac{24 \times 10^9}{Clock\ Rate_B}
]

所以：

[
Clock\ Rate_B = \frac{24 \times 10^9}{6} = 4 \times 10^9
]

**答案：計算機 B 的目標時脈速度為 4 GHz。**

### 題目 4：比較程式碼片斷(Comparing Code Segments，比較程式碼片段)

**題目：**
某硬體設計提供三種指令類別，其 **CPI** 如下：

| 指令類別 |  A |  B |  C |
| ---- | -: | -: | -: |
| CPI  |  1 |  2 |  3 |

現在有兩種程式碼序列，其各類指令數如下：

| 程式碼序列 |  A |  B |  C |
| ----- | -: | -: | -: |
| 1     |  2 |  1 |  2 |
| 2     |  4 |  1 |  1 |

問：

1. 哪一個程式碼序列執行**較多條指令**？
2. 哪一個程式碼序列**較快**？
3. 各序列的 **CPI** 為何？

**解答：**

#### 第 1 問：比較指令總數

序列 1：

[
2+1+2=5
]

序列 2：

[
4+1+1=6
]

**答案：序列 2 執行較多條指令。**

---

#### 第 2 問：計算總 clock cycles

公式：

[
Clock\ Cycles = \sum (CPI_i \times Instruction\ Count_i)
]

#### 序列 1

[
Clock\ Cycles_1=(2\times1)+(1\times2)+(2\times3)
]

[
=2+2+6=10
]

#### 序列 2

[
Clock\ Cycles_2=(4\times1)+(1\times2)+(1\times3)
]

[
=4+2+3=9
]

因為 **9 < 10**，所以：

**答案：序列 2 較快。**

---

#### 第 3 問：計算 CPI

CPI 公式：

[
CPI = \frac{Clock\ Cycles}{Instruction\ Count}
]

#### 序列 1

[
CPI_1 = \frac{10}{5}=2.0
]

#### 序列 2

[
CPI_2 = \frac{9}{6}=1.5
]

**答案：**

* 序列 1 的 CPI = **2.0**
* 序列 2 的 CPI = **1.5**

---

### 幫你整理成超短版重點

#### 這幾題其實都在考同一件事

1. **效能和時間成反比**
2. **CPU Time 不只看 clock rate**
3. **還要一起看 instruction count、CPI、clock cycle time**
4. **指令比較多，不一定比較慢**
5. **CPI 比較低，也不一定就一定比較快**

---

### 你最該背的公式

\[
CPU\ Time = Instruction\ Count \times CPI \times Clock\ Cycle\ Time
\]

\[
CPU\ Time = \frac{Clock\ Cycles}{Clock\ Rate}
\]

\[
\frac{Performance_X}{Performance_Y}
===================================
\frac{Execution\ Time_Y}{Execution\ Time_X}
\]

這些公式正是 Berkeley 架構課中整理 CPU 效能時的標準寫法。([EECS Berkeley][1])
