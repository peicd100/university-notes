C-1. Enabled 2-to-4 Decoder 優先實作

解碼器的三種建模｜來源：複習 PDF 投影片 16–17

C-1.1　Dataflow

QUESTION

Design a combinational 2-to-4 decoder with a 2-bit input a, a 1-bit enable en, and a 4-bit output y. When en=0, all outputs are zero. When en=1, only y[a] is one. Assume binary inputs.

Write a complete module named decoder_df using four Boolean continuous assignments.

Exam Answer｜考試作答Code
module decoder_df(input [1:0] a, input en, output [3:0] y);
    assign y[0] = en & ~a[1] & ~a[0];
    assign y[1] = en & ~a[1] &  a[0];
    assign y[2] = en &  a[1] & ~a[0];
    assign y[3] = en &  a[1] &  a[0];
endmodule
學習講解推導與提醒｜理解用，不必照抄

Decoder（解碼器）把二進位編號轉成 one-hot（只有一位為 1）。例如 a=2，只允許 y[2] 為 1，因此該位條件是 en=1、a[1]=1、a[0]=0。先寫每個輸出的成立條件，再翻成 AND。

C-1.2　Structural

QUESTION

Implement the same decoder as a complete module named decoder_str. Use only built-in not and and primitives.

Exam Answer｜考試作答Code
module decoder_str(input [1:0] a, input en, output [3:0] y);
    wire n1, n0;
    not i1(n1, a[1]);
    not i0(n0, a[0]);
    and g0(y[0], en, n1,   n0);
    and g1(y[1], en, n1,   a[0]);
    and g2(y[2], en, a[1], n0);
    and g3(y[3], en, a[1], a[0]);
endmodule
學習講解推導與提醒｜理解用，不必照抄

兩個 NOT 先產生 a[1]、a[0] 的反相；四個 AND 各自辨識一個編號。Primitive 的第一個接腳是輸出。這裡不能只用 assign y = en ? ...，因為本小題指定 Gate Primitive。

C-1.3　Behavioral

QUESTION

Implement the decoder as a complete module named decoder_bh using always @(*) and case. Assign all output bits for every input condition.

Exam Answer｜考試作答Code
module decoder_bh(input [1:0] a, input en, output reg [3:0] y);
    always @(*) begin
        y = 4'b0000;
        if (en) begin
            case (a)
                2'b00: y = 4'b0001;
                2'b01: y = 4'b0010;
                2'b10: y = 4'b0100;
                2'b11: y = 4'b1000;
                default: y = 4'b0000;
            endcase
        end
    end
endmodule
學習講解推導與提醒｜理解用，不必照抄

每次開始先把 y 全部清 0，再依 en 與 a 改成正確的 one-hot 值。不能只把這次被選到的位元設為 1，卻讓其他位元保留前次值。

C-2. DEMUX: Zero versus High Impedance 優先實作

解多工器與未選輸出｜來源：複習 PDF 投影片 18

C-2.1　Zero-filled DEMUX

QUESTION

Write a complete behavioral module demux4_zero with one-bit input d, two-bit input sel, and four-bit output y. Route d to y[sel] and drive every unselected output to zero. Assume binary inputs.

Exam Answer｜考試作答Code
module demux4_zero(input d, input [1:0] sel, output reg [3:0] y);
    always @(*) begin
        y = 4'b0000;
        y[sel] = d;
    end
endmodule
學習講解推導與提醒｜理解用，不必照抄

DEMUX（解多工器）不是從多個輸入挑一個，而是把一個輸入分送到選中的輸出。y = 0 定義未選線的值；接著只覆寫 y[sel]。

C-2.2　Tri-state DEMUX

QUESTION

Write a complete module demux4_z for the same routing function, but make every unselected output high impedance. Use four bufif1 primitives; continuous assignments may generate their controls.

Exam Answer｜考試作答Code
module demux4_z(input d, input [1:0] sel, output [3:0] y);
    wire s0, s1, s2, s3;
    assign s0 = (sel == 2'b00);
    assign s1 = (sel == 2'b01);
    assign s2 = (sel == 2'b10);
    assign s3 = (sel == 2'b11);

    bufif1 u0(y[0], d, s0);
    bufif1 u1(y[1], d, s1);
    bufif1 u2(y[2], d, s2);
    bufif1 u3(y[3], d, s3);
endmodule
學習講解推導與提醒｜理解用，不必照抄

每個 bufif1 都有自己的輸出線；只有 sel 相等的那一顆啟用。這和考古題兩個 Buffer 共接同一條 MUX 輸出的接線不同。Z（高阻抗）表示不驅動，不能以 0 代替。

C-3. Four-bit Rotate in Three Styles 優先實作

循環位移與接線｜來源：複習 PDF 投影片 19–20

C-3.1　Dataflow

QUESTION

Design a combinational four-bit rotator. With left=1, rotate data[3:0] left by one bit; with left=0, rotate it right by one bit. The bit shifted out must wrap around. Assume binary inputs. Do not use a clock.

Write a complete module rotate4_df using a conditional operator and concatenations.

Exam Answer｜考試作答Code
module rotate4_df(input [3:0] data, input left, output [3:0] y);
    assign y = left ? {data[2:0], data[3]}
                    : {data[0], data[3:1]};
endmodule
學習講解推導與提醒｜理解用，不必照抄

Rotate（循環位移）不會丟掉最外側位元。左轉時原 data[3] 放到最低位；右轉時原 data[0] 放到最高位。<< 或 >> 單獨使用不會自動繞回。

C-3.2　Structural

QUESTION

Write rotate4_str using four instances of the provided one-bit module mux2_g(y, d0, d1, s). It selects d0 when s=0 and d1 when s=1. Do not redefine mux2_g.

Exam Answer｜考試作答Code
module rotate4_str(input [3:0] data, input left, output [3:0] y);
    mux2_g u3(y[3], data[0], data[2], left);
    mux2_g u2(y[2], data[3], data[1], left);
    mux2_g u1(y[1], data[2], data[0], left);
    mux2_g u0(y[0], data[1], data[3], left);
endmodule
學習講解推導與提醒｜理解用，不必照抄

先把每個輸出在 left=0、left=1 時的來源列出來，再接 MUX。四個 MUX 只是共同受 left 控制，彼此不是串成四級。

C-3.3　Behavioral

QUESTION

Write a complete module rotate4_bh using always @(*) and if ... else.

Exam Answer｜考試作答Code
module rotate4_bh(input [3:0] data, input left, output reg [3:0] y);
    always @(*) begin
        if (left)
            y = {data[2:0], data[3]};
        else
            y = {data[0], data[3:1]};
    end
endmodule
學習講解推導與提醒｜理解用，不必照抄

輸出用 reg 是因為它在程序區塊中賦值；本題沒有事件邊緣，兩個分支又都完整賦值，因此是組合邏輯，不是 Shift Register。

C-4. Highest-bit Priority Encoder 優先實作

最高位優先編碼器｜來源：複習 PDF 投影片 21

C-4.1　Behavioral encoder

QUESTION

Write a complete module priority4. The four-bit input in may contain multiple ones. Output the position of the highest set bit as two-bit code. Set valid=1 if any bit is one. For in=0000, output valid=0 and code=0. Assume binary inputs.

Exam Answer｜考試作答Code
module priority4(input [3:0] in, output reg [1:0] code,
                 output reg valid);
    always @(*) begin
        valid = |in;
        if      (in[3]) code = 2'd3;
        else if (in[2]) code = 2'd2;
        else if (in[1]) code = 2'd1;
        else            code = 2'd0;
    end
endmodule
學習講解推導與提醒｜理解用，不必照抄

Priority（優先權）靠 if／else if 的先後順序決定；先檢查 in[3]，低位就不能覆寫高位的決定。valid 用來區分「沒有 1」與「只有最低位為 1」，因為兩者的 code 都是 0。

C-4.2　Boolean equations

QUESTION

Give dataflow assignments for the same function. For this separate implementation, assume valid and code are wires.

Exam Answer｜考試作答Code
assign valid   = |in;
assign code[1] = in[3] | in[2];
assign code[0] = in[3] | (~in[2] & in[1]);
學習講解推導與提醒｜理解用，不必照抄

code[0] 不能直接寫成 in[3] | in[1]。當 in[2]=1 且 in[3]=0 時，無論 in[1] 是什麼，都應輸出 2，即 code[0]=0；所以低位條件要加上 ~in[2]。

C-5. Eight-bit Even-parity Generator 優先實作

偶同位檢查位元產生器｜來源：複習 PDF 投影片 22

C-5.1　Reduction operator

QUESTION

Design a parity generator for eight-bit binary input data. Choose one-bit p so that {data,p} contains an even number of ones. Write a complete dataflow module parity8_df using a reduction operator.

Exam Answer｜考試作答Code
module parity8_df(input [7:0] data, output p);
    assign p = ^data;
endmodule
學習講解推導與提醒｜理解用，不必照抄

p 不是「輸入已經有偶數個 1」時設為 1。它是要補上的那一位：原本奇數個 1 就補 1，原本偶數個 1 就補 0。這正是 Reduction XOR 的輸出。

C-5.2　XOR-tree structure

QUESTION

Write a complete structural module parity8_str using only two-input xor primitives. Draw a balanced XOR tree and state the number of gates and logic levels.

Exam Answer｜考試作答Code + diagram
module parity8_str(input [7:0] data, output p);
    wire [3:0] t;
    wire [1:0] u;
    xor g0(t[0], data[0], data[1]);
    xor g1(t[1], data[2], data[3]);
    xor g2(t[2], data[4], data[5]);
    xor g3(t[3], data[6], data[7]);
    xor g4(u[0], t[0], t[1]);
    xor g5(u[1], t[2], t[3]);
    xor g6(p, u[0], u[1]);
endmodule

The tree contains seven two-input XOR gates and three logic levels.

學習講解推導與提醒｜理解用，不必照抄

第一層把 8 個輸入兩兩合併成 4 個結果，第二層變成 2 個，第三層變成 1 個。Gate 數為 4+2+1=7。此處「三層」是邏輯深度，不是三個 Clock Cycle。

C-5.3　Procedural loop

QUESTION

Write a complete behavioral module parity8_bh with a procedural for loop. Do not use a clock or reduction XOR in this version.

Exam Answer｜考試作答Code
module parity8_bh(input [7:0] data, output reg p);
    integer i;
    always @(*) begin
        p = 1'b0;
        for (i = 0; i < 8; i = i + 1)
            p = p ^ data[i];
    end
endmodule
學習講解推導與提醒｜理解用，不必照抄

每次輸入變動，先令 p=0，再把八位依序 XOR 進去。必須使用 Blocking Assignment，讓下一次迴圈讀到這次的新 p。若不先清 0，就不再是單純由目前 data 決定的結果。

C-6. Four-bit ALU and Zero Flag 優先實作

算術邏輯單元與零旗標｜來源：複習 PDF 投影片 23

C-6.1　Complete ALU

QUESTION

Write a complete behavioral module alu4 with four-bit unsigned inputs a and b, two-bit input op, four-bit output y, and one-bit output zero. Select AND, OR, addition, and subtraction for op=00,01,10,11, respectively. Keep only the low four result bits. Set zero=1 exactly when y=0. Use y=0 for a case mismatch. Do not add carry or overflow ports.

Exam Answer｜考試作答Code
module alu4(input [3:0] a, b, input [1:0] op,
            output reg [3:0] y, output reg zero);
    always @(*) begin
        case (op)
            2'b00: y = a & b;
            2'b01: y = a | b;
            2'b10: y = a + b;
            2'b11: y = a - b;
            default: y = 4'b0000;
        endcase
        zero = (y == 4'b0000);
    end
endmodule
學習講解推導與提醒｜理解用，不必照抄

先用 Blocking Assignment 算出這次的 y，再判斷它是否等於 0。若 y 用 <=，同一區塊後面的 zero 可能讀到舊 y。題目只要求低 4 位，不應額外加上未要求的 Carry／Overflow 輸出。

C-7. Leading-zero Counter 優先實作

前導零計數器的設計｜來源：複習 PDF 投影片 24

C-7.1　Complete LZC

QUESTION

Write a complete combinational module lzc4 that counts consecutive zeros from the MSB of four-bit binary input data. Output count=4 for 0000. Choose the minimum output width that represents all results and justify it.

Exam Answer｜考試作答Code + width
module lzc4(input [3:0] data, output reg [2:0] count);
    always @(*) begin
        if      (data[3]) count = 3'd0;
        else if (data[2]) count = 3'd1;
        else if (data[1]) count = 3'd2;
        else if (data[0]) count = 3'd3;
        else             count = 3'd4;
    end
endmodule

Three output bits are required because the result range is 0 through 4.

學習講解推導與提醒｜理解用，不必照抄

先看 MSB：只要 data[3]=1，前導零立即是 0。直到最右邊都沒有遇到 1，才回傳 4。不是計算所有 0 的總數，也不是把開頭的 1 一起算進去。

C-8.2　Behavioral implementation

QUESTION

Write a complete module fsm3(input clk, rst_n, en, output reg y). Separate the clocked state register from combinational next-state and output logic.

Exam Answer｜考試作答Code
module fsm3(input clk, rst_n, en, output reg y);
    localparam S0 = 2'd0, S1 = 2'd1, S2 = 2'd2;
    reg [1:0] state, next;

    always @(posedge clk or negedge rst_n) begin
        if (!rst_n)
            state <= S0;
        else
            state <= next;
    end

    always @(*) begin
        next = state;
        case (state)
            S0: if (en) next = S1;
            S1: if (en) next = S2;
            S2: if (en) next = S0;
            default: next = S0;
        endcase
        y = (state == S2);
    end
endmodule
學習講解推導與提醒｜理解用，不必照抄

先在組合區塊令 next=state，代表預設保持，再依狀態與 en 改寫。state 只在一個時序區塊中用 <= 更新；next 和 y 用 = 計算。default 把未使用的 11 導回 S0，而不是把所有未啟用情況都清成 S0。

C-9.1　Infer the hardware

QUESTION

Assume all signals below are one bit. Identify and draw the hardware inferred by each fragment. Does the keyword reg alone imply a flip-flop?

// Fragment A
reg y;
always @(*) y = a & b;

// Fragment B
reg q;
always @(*)
    if (en) q = d;
Exam Answer｜考試作答Explanation + diagram

Fragment A infers combinational AND logic. Fragment B infers a level-sensitive latch: q follows d while en=1 and holds its old value while en=0. No, reg alone does not imply a flip-flop.

學習講解推導與提醒｜理解用，不必照抄

先問「哪個條件下更新、哪個條件下保留」，而不是看到 reg 就畫 FF。A 每種輸入都有新的 y；B 在 en=0 時沒有賦值，因此必須保存之前的 q。

C-9.2　Missing sensitivity

QUESTION

Consider always @(a) y = a & b;. The block has just evaluated with a=1 and b=0, so y=0. Now only b changes to 1. What does this RTL simulation leave in y? What should a combinational AND output be? Rewrite the block correctly.

Exam Answer｜考試作答Trace + corrected code

The RTL simulation leaves y=0 because no event occurs on a. The combinational AND result should be 1.

always @(*)
    y = a & b;
學習講解推導與提醒｜理解用，不必照抄

Sensitivity List（敏感度列表）決定程序何時重新執行。漏掉 b，不是把 b 從公式刪掉，而是 b 變動時不重算。補成 @(*) 讓讀到的輸入變動能觸發運算。這和漏寫輸出分支的問題不同。

C-9.3　Remove unintended storage

QUESTION

The required function is now q=d when en=1, and q=0 when en=0. Rewrite Fragment B as combinational logic. Is changing the sensitivity list alone sufficient?

Exam Answer｜考試作答Code + explanation

    q = 1'b0;
    if (en)
        q = d;

No. The output also needs an assignment when en=0.

學習講解推導與提醒｜理解用，不必照抄

原片段已經有 @(*)，卻還是 Latch，因為 en=0 時仍需保留 q。新規格要求 en=0 輸出 0，所以先給預設 0，再由 if 覆寫。@(*) 解決「什麼時候算」，完整賦值解決「每種條件算成什麼」。
