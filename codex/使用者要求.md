# 使用者要求

- 全程使用繁體中文。
- 中文檔案使用 UTF-8（無 BOM）。
- 決策優先採穩定、成功率高的做法；可先查官方文件與社群經驗後直接採用較穩方案，再在回報時說明。
- 每次完成任務後，要說明怎麼做、用了什麼。
- 沒有被要求修改檔案時，不主動改檔。
- 使用 conda 管理 Python 環境；此專案目前使用 `mkdocs` 環境。
- 單頁 preview 流程希望可直接用終端命令加 Markdown 路徑，並走 `mkdocs_desk` 環境啟動 preview serve。
- 單頁 preview 的短命令要支援 `.\p <Markdown 路徑>`，由 `p.bat` 轉交給既有 `preview.bat`。
- 專案修改時要維護協作檔與重要決策紀錄。
- 若有 GPU 可用功能，優先 GPU；偵測不到再退 CPU。
- 人工驗證若需要保留輸出檔，統一放 `codex/tmp/`，不要散在專案根目錄。
